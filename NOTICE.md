## Game data and icons

equipment box icons, class icons and note icons in [docs/assets/icons/](docs/assets/icons/) and
[docs/assets/notes/](docs/assets/notes/), are generated by [scripts/build_data.py](scripts/build_data.py)

archives or keys are redistributed**; only the generated tables and icons are committed.

icons, generated by the same script.
